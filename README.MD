# Mein Übungsheft 🇩🇪

An open-source, offline-friendly German learning PWA for structured
vocabulary, conjugation, grammar and adaptive practice.

[Screenshot / GIF]

## Why this project exists

German learners often have vocabulary, grammar exercises and progress
tracking scattered across separate resources.

Mein Übungsheft aims to provide a focused, open-source learning
environment that combines them in one application.

## Features

- German vocabulary practice
- German → English and English → German exercises
- Verb conjugation practice
- Structured learning sessions
- Progress and mastery tracking
- XP / streak / gamification systems
- Text-to-speech
- Offline-friendly PWA
- Responsive mobile-first interface
- Accessibility-focused interaction design

## Project status

🚧 Active development

The project is currently focused on A1–B1 German learning workflows.
APIs and data structures may change while the learning engine matures.
