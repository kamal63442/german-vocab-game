Possessiv — Neues Set

21 Worksheet-Fragen (Nominativ) + generierte Fragen aus neuem Bank (20 Nomen) — so sieht es im Spiel aus

Was passiert beim Ersetzen?

Alt: 34 Nomen (z. B. Computer, Ball, Auto …) → 612 mögliche Fragen (34×9×2)
Neu: 20 Nomen aus dem Worksheet (Tasche, Hund, Mutter … Höhle) → 360 mögliche Fragen (20×9×2, Nominativ+Akkusativ) + exakt die 21 Blatt-Sätze als Vorlagen.
Ziel: Altes Set komplett durch neues ersetzen. Unten siehst du zuerst die 21 Blatt-Fragen 1:1, danach eine Stichprobe generierter Fragen aus dem neuen Bank.
